# 🎬 Movie Search

A simple and responsive Movie Search web application that allows users to search for movies and view details such as posters, ratings, release dates, and overviews using a movie API.

## 🚀 Features

- 🔍 Search movies by title
- 🎥 Display movie posters
- ⭐ View movie ratings
- 📅 Show release dates
- 📝 Movie overview/description
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Movie API (TMDb or OMDb)

## 📂 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/movie-search.git
   ```

2. Navigate to the project folder:
   ```bash
   cd movie-search
   ```

3. Open `index.html` in your browser.

## 🔑 API Setup

1. Get an API key from TMDb or OMDb.
2. Add your API key to the JavaScript file:

```javascript
const API_KEY = "YOUR_API_KEY";
```
